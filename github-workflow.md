# GitHub Collaboration Workflow

## Remote Repository
A remote repository is a version of the project hosted on a platform such as GitHub.

## Clone
Clone downloads a repository and its Git history to a local computer

## Fetch
Fetch downloads updates from a remote repository without integrating them into the current branch.

## Pull
Pull fetches remote changes and integrates them into the current branch.

## Push
Push uploads local commits to a remote repository.

## Pull Request
A Pull Request proposes changes from one branch to another for review before merging.

## Typical Workflow

1. Clone the repository.
2. Create a feature branch.
3. Make changes.
4. Commit changes.
5. Push the branch.
6. Open a Pull Request.
7. Review and merge.
