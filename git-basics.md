# Git Basics

Git is a distributed version control system used to track changes in source code.

## Basic Commands

- git init: Initialize a Git repository.
- git status: Check the working tree status.
- git add: Stage changes for a commit.
- git commit: Save staged changes in repository history.
- git log: View commit history.
- git diff: View changes between versions.

## Three Areas

1. Working Directory: Where files are modified.
2. Staging Area: Where changes are prepared for commit.
3. Repository: Where committed snapshots are stored.
