# Git Practice Assignment

This repository demonstrates practical Git and GitHub workflows.

## Topics Covered
- Git basics and commits
- Branching and checkout
- Merge and rebase
- Remote repositories
- Pull requests
- Development, staging, and production environments

## Branches
- main: Stable project branch
- feature-git-concepts: Git concepts and branching practice
- feature-workflow-notes: Collaboration and GitHub workflow documentation

## Workflow
Create a feature branch, make changes, commit them, push to GitHub, and open a Pull Request for review.
